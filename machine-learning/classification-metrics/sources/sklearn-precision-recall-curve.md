# scikit-learn API, `sklearn.metrics.precision_recall_curve` (1.9.1)

Supports: precision and recall are computed for predictions with score >= each threshold; the first precision and recall values are precision = class balance and recall = 1.0, for a classifier that always predicts positive; the last values are precision 1 and recall 0 and have no threshold, which "ensures that the graph starts on the y axis".
