# scikit-learn User Guide, "6. Visualizations" (1.9.1)

Supports: a `Display` object stores the computed values needed for plotting with Matplotlib, built with `from_estimator` (a fitted estimator and data) or `from_predictions` (true and predicted values); the available displays include `ConfusionMatrixDisplay` (confusion matrix), `RocCurveDisplay` (ROC curve), `PrecisionRecallDisplay` (precision-recall), `DetCurveDisplay` (detection error tradeoff curve) and `CalibrationDisplay` (calibration curve, also known as reliability diagram) (Section 6.1.1).
