# scikit-learn API, `sklearn.metrics.roc_curve` (1.9.1)

Supports: `fpr[i]` and `tpr[i]` are the rates of predictions with score >= `thresholds[i]`; the thresholds are decreasing and the first is set to infinity to represent a classifier that always predicts negative (fpr = 0, tpr = 0); `drop_intermediate` (default True) drops collinear points, with no effect on the ROC AUC or the curve's shape.
