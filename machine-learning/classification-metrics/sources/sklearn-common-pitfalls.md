# scikit-learn User Guide, "12. Common pitfalls and recommended practices" (1.9.1)

Supports: data leakage is using information at model-building time that would not be available at prediction time, which gives overly optimistic performance estimates and poorer performance on novel data; a common cause is not keeping the test and train subsets separate; "Test data should never be used to make choices about the model" (Section 12.2).
