# scikit-learn API, `sklearn.metrics.confusion_matrix` (1.9.1)

Supports: $C_{i,j}$ is the number of observations known to be in group $i$ and predicted to be in group $j$ (rows = true label, columns = predicted label); in the binary case true negatives are $C_{0,0}$, false negatives $C_{1,0}$, true positives $C_{1,1}$ and false positives $C_{0,1}$. Also (for the reporting Finding): `normalize` set to `'true'`, `'pred'` or `'all'` normalizes the matrix over the true conditions (rows), the predicted conditions (columns) or the whole population, and `None` (the default) leaves counts.
