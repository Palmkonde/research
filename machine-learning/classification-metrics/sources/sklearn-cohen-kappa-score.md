# scikit-learn API, `sklearn.metrics.cohen_kappa_score` (1.9.1)

Supports: Cohen's kappa expresses the agreement between two annotators as $\kappa = (p_o - p_e)/(1 - p_e)$, where $p_o$ is the observed agreement ratio and $p_e$ the expected agreement when both annotators assign labels randomly, estimated from a per-annotator empirical prior over the class labels; kappa lies between −1 and 1, with 0 meaning no agreement beyond chance.
