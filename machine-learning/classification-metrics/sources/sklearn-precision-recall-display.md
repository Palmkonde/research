# scikit-learn API, `sklearn.metrics.PrecisionRecallDisplay` (1.9.1)

Supports: `plot_chance_level` (added in 1.3) plots the chance level, which "is the prevalence of the positive label computed from the data" passed to `from_estimator` or `from_predictions`; the average precision can label each curve in the legend; AP is computed without interpolation, so the curve is drawn step-wise by default to stay consistent with it, and an interpolated drawing "will not be strictly consistent with the reported average precision" (Notes).
