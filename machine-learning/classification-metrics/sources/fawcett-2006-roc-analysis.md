# Fawcett, "An introduction to ROC analysis" (Pattern Recognition Letters 27, 2006, 861–874)

Supports: the four outcomes TP, FP, TN, FN and the confusion matrix (Section 2, Fig. 1, which puts the true class on columns and the hypothesized class on rows); tp rate (hit rate, recall), fp rate (false alarm rate), sensitivity = recall, specificity = TN/(FP+TN) = 1 − fp rate, positive predictive value = precision; Fig. 1's formulas for precision, recall, accuracy = (TP+TN)/(P+N) and F-measure = 2/(1/precision + 1/recall); Section 4.2's argument that metrics using both classes (accuracy, precision, lift, F score) change with class skew while tp rate and fp rate do not. Also (for the ROC/PR Finding): ROC corner points (0, 0) never positive, (1, 1) always positive, (0, 1) perfect (Section 2); the diagonal $y = x$ is random guessing (Section 3.1); a scoring classifier plus a threshold traces the curve, a finite test set gives a step function, and instances are sorted by decreasing score (Sections 4 and 5, Fig. 3, Algorithm 1); ROC curves are insensitive to changes in class distribution, while the PR curves in Fig. 5 change when negatives are increased tenfold (Section 4.2); tied scores give the expected diagonal segment (Section 5, Fig. 6); AUC lies in [0, 1], random guessing has area 0.5, AUC equals the probability of ranking a random positive above a random negative and the Wilcoxon test of ranks, and is computed by summing trapezoids (Section 7, Algorithm 2) Also (for the class-imbalance Finding): class skews of $10^1$ and $10^2$ are very common in real-world domains and skews up to $10^6$ have been observed, and with a shifted distribution the conclusion of which classifier is superior can change in some cases (Section 4.2); ROC graphs decouple classifier performance from class skew and error costs, which gives them advantages over precision-recall graphs (Section 11). Also (for the decision-threshold Finding): scores may be strict probabilities or uncalibrated scores where only "a higher score indicates a higher probability", and a scoring classifier plus a threshold gives a discrete classifier, one ROC point per threshold, with lower thresholds moving from the "conservative" to the "liberal" region; in Fig. 3 the best accuracy is at threshold ≥ 0.54 rather than 0.5 (Section 4); the ROC curve measures relative scores, accuracy at a 0.5 threshold would be appropriate only for proper (calibrated) probabilities, Fig. 4 shows a perfect ROC curve with 80% accuracy at 0.5, calibration or ROC-based choice of operating points fixes this, and comparing models from different classes at a common threshold is meaningless (Section 4.1); eq. (1), two ROC points have the same expected cost when $(TP_2 - TP_1)/(FP_2 - FP_1) = c(Y,n)\,p(n)/ig(c(N,p)\,p(p)ig) = m$, the slope of an iso-performance line; lines more northwest (larger TP-intercept) have lower expected cost, a classifier is potentially optimal only on the ROC convex hull, and the examples m = 10 (negatives 10:1, equal costs) and m = 1/10 (balanced, false negative 10 times as costly) (Section 6, Fig. 7); a high-AUC classifier can perform worse in a specific region of ROC space than a low-AUC one, and a scoring classifier used at one fixed threshold is a single point, equal at that point and worse elsewhere (Section 7, Fig. 8).
