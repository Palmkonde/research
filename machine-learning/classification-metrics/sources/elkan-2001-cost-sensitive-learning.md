# Elkan, "The Foundations of Cost-Sensitive Learning" (Proceedings of the 17th IJCAI, 2001)

Supports: the optimal prediction is the class with the lowest expected cost, computed with the conditional probability of each class given the example, and it can be optimal to act as if one class is true even when another is more probable (Section 1); the cost matrix convention $c(i,j)$ = cost of predicting $i$ when the true class is $j$, with rows = predicted and columns = actual, so a false positive costs $c_{10}$ and a false negative $c_{01}$, and the "reasonableness" conditions $c_{10} > c_{00}$, $c_{01} > c_{11}$ (Section 1.1); scaling or shifting the cost matrix leaves the optimal decisions unchanged (Section 1.1); predict class 1 if and only if $(1-p)\,c_{10} + p\,c_{11} \le (1-p)\,c_{00} + p\,c_{01}$ with $p = P(j=1 \mid x)$, which gives the threshold $p^* = (c_{10}-c_{00})/(c_{10}-c_{00}+c_{01}-c_{11})$ in eq. (2), predicting class 1 if and only if $p \ge p^*$, so a 2x2 cost matrix has only one degree of freedom for decisions (Section 1.3); standard learners aiming at accuracy implicitly decide at probability threshold 0.5 (Section 2); the recommended approach is to learn a classifier from the training set as given and compute optimal decisions explicitly from its probability estimates (abstract).
