# Dietterich, "Approximate Statistical Tests for Comparing Supervised Classification Learning Algorithms" (Neural Computation 10(7): 1895–1924, 1998)

Supports: of five tests, the difference-of-two-proportions test and the paired t test over several random train/test splits have high Type I error and "should never be used", the 10-fold cross-validated paired t test has somewhat elevated Type I error, McNemar's test has low Type I error, and the new 5x2cv test has acceptable Type I error and is slightly more powerful than McNemar's; for algorithms that can be run only once McNemar's test is the only one with acceptable Type I error, and for algorithms that can be run ten times 5x2cv is recommended (abstract); McNemar's test trains both algorithms on one training set R, tabulates test examples misclassified by both ($n_{00}$), by A only ($n_{01}$), by B only ($n_{10}$) and by neither ($n_{11}$), and compares $(\lvert n_{01} - n_{10}\rvert - 1)^2/(n_{01} + n_{10})$, which includes a continuity correction, with $\chi^2_{1,0.95} = 3.841459$; it does not measure variation due to the choice of training set or the algorithm's internal randomness (Section 3.1); the two error rates measured on the same test set are not independent (Section 3.2); in the resampled paired t test the trial differences are not independent because the test sets and training sets of the trials overlap (Section 3.3); in k-fold CV the test sets are independent but the training sets overlap, each pair sharing 80% of the examples in 10-fold CV, and the measured correlation between fold differences was 0.03778, significantly different from 0 with $p < 10^{-10}$ (Section 3.4).
